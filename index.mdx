OuterProduct gives you a Python SDK and hosted API for training tabular ML models and making them explainable. From a single `pip install`, you can train a model, generate per-row predictions, and understand which features drive every decision — including counterfactual scenarios and population-level pattern analysis.

## Get started in three steps

<Steps>
  <Step title="Install the SDK">
    ```bash
    pip install outerproduct
    ```
  </Step>
  <Step title="Set your API key">
    ```bash
    export OUTERPRODUCT_API_KEY="your-api-key"
    ```
    Get your key from the [OuterProduct Console](https://console.outerproduct.com).
  </Step>
  <Step title="Train and explain">
    ```python
    import outerproduct as op

    op.init()

    dataset = op.Dataset.from_csv("customers.csv")
    model = op.reasoning.fit(dataset, task=op.BinclassConfig(label_column="churn")).wait()

    predictions, reasoning = model.predict_and_explain(op.Dataset.from_csv("customers_test.csv"))
    print(reasoning.feature_names)
    print(reasoning.attributions.shape)
    ```
  </Step>
</Steps>
