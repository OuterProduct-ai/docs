## `op.init()`

```python
init(api_key: str | None = None, *, base_url: str | None = None) -> None
```

Configure the OuterProduct SDK for the current Python process.

Call once near the top of your program. Subsequent operations
(training, prediction, uploads) read credentials and the API base URL
from the state recorded here.

Examples
--------
```python
import outerproduct as op
op.init(api_key="op_live_...")
```

Parameters

    If omitted, the `OUTERPRODUCT_API_KEY` environment variable is

## `op.use_client()`

```python
use_client(client: OuterProductClient) -> Generator[None, None, None]
```

Use `client` for every SDK HTTP call inside this block.

Inside the `with` block, the SDK's internal client helper yields
`client` rather than building one from `op._state`. The caller
owns `client`'s lifecycle — the SDK will not close it.

Designed for service-style consumers (e.g. an MCP server) that need
to thread per-request credentials through SDK calls without mutating
global state. Contextvars propagate across `asyncio.to_thread` and
`asyncio.TaskGroup`, so this works inside async dispatch.

Examples
--------
```python
from outerproduct.client import OuterProductClient
import outerproduct as op
```

    # Mint a per-request bearer (e.g. a short-lived JWT) and use it
    # for every SDK call inside the `with` block.
    with OuterProductClient.from_credentials(base_url, per_request_token) as client:
        with op.use_client(client):
            model = op.ReasoningModel(id="mdl-1", feature_names=["a","b"])
            preds = model.predict(X)

## `op.use_aclient()`

```python
use_aclient(client: AsyncOuterProductClient) -> Generator[None, None, None]
```

Async mirror of `use_client` — inject an `AsyncOuterProductClient`.

Inside this block, the SDK's async HTTP helpers (`_aclient` /
`_aresolve_client`, and therefore every `a`-prefixed/async SDK call)
use `client` instead of building one from `op._state`. The caller owns
`client`'s lifecycle — the SDK will not `aclose` it.

This is itself an ordinary (synchronous) context manager — it only sets a
contextvar and does no I/O — so it can be entered with a plain `with`
even though the client it injects is async::

    async with AsyncOuterProductClient.from_credentials(base, token) as client:
        with op.use_aclient(client):
            await op.reasoning.afit(ds, task=...)

## `op.get_models()`

```python
get_models() -> list['Model']
```

List models owned by the configured caller.

Rows tagged `model_type='reasoning'` come back as
`ReasoningModel`; trainer rows come back
as `Model`. Both expose `id` already
stamped from the wire response; richer attributes (`schema`,
`feature_names`) lazy-fetch on first use.

## `op.col()`

```python
col(name: str) -> Expr
```

A column-reference expression for `filter` / `select` / `with_column`.

`ws.table("users").filter(op.col("age") >= 18)`. Wraps DataFusion's `col`
(imported lazily — DataFusion is heavy), quoting `name` so DataFusion does
not case-fold it (a raw `"Churn"` would resolve to `churn`).
