`outerproduct.Dataset` is the typed, server-backed data handle that all OuterProduct training and inference functions accept. You don't construct it from raw data directly — you stage local data in an `op.LocalDataset` (from a file, DataFrame, or array) and call `.upload()`, or you reference a [connector](/sdk/connectors) (S3, Snowflake, Databricks). The target column is not marked on the dataset itself — you name it later via the `task` config (e.g. `op.BinclassConfig(label_column=...)`) when you configure a trainer or call `reasoning.fit()`.

<Note>
  You **cannot** build a `Dataset` from a raw `pandas.DataFrame` or `numpy.ndarray` directly (`op.Dataset(df)` is not supported). Stage the data through `op.LocalDataset` and call `.upload()`.
</Note>

## Building a dataset

Stage local data in an `op.LocalDataset` and call `.upload()` — it serializes the rows, uploads them via a presigned URL, and returns a server-backed `Dataset`:

```python
import pandas as pd
import outerproduct as op

df = pd.DataFrame({"age": [25, 32, 47], "income": [40000, 75000, 120000]})
dataset = op.LocalDataset.from_pandas(df).upload()
```

## LocalDataset constructors

Each constructor returns a `LocalDataset` holding your rows. Call `.upload()` (or `.aupload()` for async) on it to get a `Dataset`.

### `LocalDataset.from_csv()`

Stage a local CSV file.

```python
op.LocalDataset.from_csv(path)
```

<ParamField body="path" type="string" required>
  Path to the CSV file on your local filesystem.
</ParamField>

```python
import outerproduct as op

dataset = op.LocalDataset.from_csv("customers.csv").upload()
```

---

### `LocalDataset.from_pandas()`

Stage an existing pandas DataFrame.

```python
op.LocalDataset.from_pandas(df)
```

<ParamField body="df" type="pd.DataFrame" required>
  A pandas DataFrame. The DataFrame index is ignored; all columns become features.
</ParamField>

```python
import pandas as pd
import outerproduct as op

df = pd.read_csv("loans.csv")
dataset = op.LocalDataset.from_pandas(df).upload()
```

---

### `LocalDataset.from_polars()`

Stage an existing polars DataFrame.

```python
op.LocalDataset.from_polars(df)
```

<ParamField body="df" type="pl.DataFrame" required>
  A polars DataFrame. All columns become features.
</ParamField>

```python
import polars as pl
import outerproduct as op

df = pl.read_csv("loans.csv")
dataset = op.LocalDataset.from_polars(df).upload()
```

---

### `LocalDataset.from_parquet()`

Stage a local Parquet file.

```python
op.LocalDataset.from_parquet(path)
```

<ParamField body="path" type="string" required>
  Path to the Parquet file on your local filesystem.
</ParamField>

<Note>
  Parquet support requires the `parquet` extra. Install it with `pip install outerproduct[parquet]`.
</Note>

```python
import outerproduct as op

dataset = op.LocalDataset.from_parquet("loans.parquet").upload()
```

---

### `LocalDataset.from_numpy()`

Stage NumPy arrays. Useful when your data is already in memory as arrays rather than a DataFrame.

```python
op.LocalDataset.from_numpy(X, y=None, feature_names=None)
```

<ParamField body="X" type="np.ndarray" required>
  Feature matrix of shape `(n_samples, n_features)`.
</ParamField>

<ParamField body="y" type="np.ndarray">
  Optional label array of shape `(n_samples,)`. When provided, it is appended to the dataset as an additional column alongside the features.
</ParamField>

<ParamField body="feature_names" type="list[str]">
  Optional list of column names for the feature matrix. Must have the same length as `X.shape[1]`. If omitted, columns are named `x0`, `x1`, etc.
</ParamField>

```python
import numpy as np
import outerproduct as op

X = np.array([[1200, 3, 2], [850, 2, 1], [2100, 4, 3]])
y = np.array([0, 0, 1])

dataset = op.LocalDataset.from_numpy(
    X,
    y,
    feature_names=["sqft", "bedrooms", "bathrooms"],
).upload()
```

<Note>
  `op.LocalDataset` also accepts a `torch.Tensor`, a 2-D `numpy.ndarray`, and nested lists, all normalized the same way.
</Note>

## Datasets from connectors

A `Dataset` can also reference data in a cloud source without uploading. Configure the credential once in the [Console](https://console.outerproduct.com), then build a connector-backed `Dataset` with `.table(...)`:

```python
import outerproduct as op

connector = op.S3Connector(connector_credential_name="prod-aws", region="us-east-1")
dataset = connector.table("s3://my-bucket/data/customers.parquet")
```

See the [Connectors reference](/sdk/connectors) for S3, Snowflake, and Databricks.

## Column Schema

Every column in a dataset carries a `Column` schema object that captures its data type. By default the schema is **inferred automatically** from the data — you rarely need to set it manually. Inspect it via `dataset.columns`.

<Note>
  The target (label) column is **not** declared on the dataset. You specify it later using the `task` config (e.g. `op.BinclassConfig(label_column=...)`) in [`Trainer.configure()`](/sdk/trainer) or `op.reasoning.fit()`.
</Note>

## Complete Example

<CodeGroup>

```python From CSV
import outerproduct as op

op.init()

dataset = op.LocalDataset.from_csv("loans.csv").upload()
model = op.reasoning.fit(dataset, task=op.BinclassConfig(label_column="approved")).wait()
```

```python From pandas
import pandas as pd
import outerproduct as op

op.init()

df = pd.read_csv("loans.csv")
dataset = op.LocalDataset.from_pandas(df).upload()
```

```python From polars
import polars as pl
import outerproduct as op

op.init()

df = pl.read_csv("loans.csv")
dataset = op.LocalDataset.from_polars(df).upload()
```

```python From NumPy
import numpy as np
import outerproduct as op

op.init()

X = np.random.rand(1000, 5)
y = (X[:, 0] > 0.5).astype(int)

dataset = op.LocalDataset.from_numpy(
    X,
    y,
    feature_names=["f0", "f1", "f2", "f3", "f4"],
).upload()
```

```python From Parquet
import outerproduct as op

op.init()

# Requires: pip install outerproduct[parquet]
dataset = op.LocalDataset.from_parquet("warehouse/transactions.parquet").upload()
```
