`outerproduct.Dataset` is the typed data handle that all OuterProduct training and inference functions accept. It wraps your tabular data together with a per-column `Column` schema, which is inferred automatically from the data by default. The target column is not marked on the `Dataset` itself — you name it later via the `label_column=` argument when you configure a trainer or call `reasoning.fit()`.

## Constructor

```python
op.Dataset(X)
```

Construct a `Dataset` directly from a pandas DataFrame or a NumPy array. For file-based sources, prefer the factory methods below.

<ParamField body="X" type="pd.DataFrame | np.ndarray" required>
  The feature matrix. All columns are included; no column is designated as the target at this stage.
</ParamField>

```python
import pandas as pd
import outerproduct as op

df = pd.DataFrame({"age": [25, 32, 47], "income": [40000, 75000, 120000]})
dataset = op.Dataset(df)
```

## Factory Methods

### `Dataset.from_csv()`

Load a Dataset from a local CSV file.

```python
op.Dataset.from_csv(path)
```

<ParamField body="path" type="string" required>
  Path to the CSV file on your local filesystem.
</ParamField>

```python
import outerproduct as op

dataset = op.Dataset.from_csv("customers.csv")
print(dataset.n_samples, dataset.n_features)
```

---

### `Dataset.from_pandas()`

Create a Dataset from an existing pandas DataFrame.

```python
op.Dataset.from_pandas(df)
```

<ParamField body="df" type="pd.DataFrame" required>
  A pandas DataFrame. The DataFrame index is ignored; all columns become features.
</ParamField>

```python
import pandas as pd
import outerproduct as op

df = pd.read_csv("loans.csv")
dataset = op.Dataset.from_pandas(df)
```

---

### `Dataset.from_parquet()`

Load a Dataset from a Parquet file.

```python
op.Dataset.from_parquet(path)
```

<ParamField body="path" type="string" required>
  Path to the Parquet file on your local filesystem.
</ParamField>

<Note>
  Parquet support requires the `parquet` extra. Install it with `pip install outerproduct[parquet]`.
</Note>

```python
import outerproduct as op

dataset = op.Dataset.from_parquet("loans.parquet")
```

---

### `Dataset.from_numpy()`

Build a Dataset from NumPy arrays. Useful when your data is already in memory as arrays rather than a DataFrame.

```python
op.Dataset.from_numpy(X, y=None, feature_names=None)
```

<ParamField body="X" type="np.ndarray" required>
  Feature matrix of shape `(n_samples, n_features)`.
</ParamField>

<ParamField body="y" type="np.ndarray">
  Optional label array of shape `(n_samples,)`. When provided, it is appended to the Dataset as an additional column alongside the features.
</ParamField>

<ParamField body="feature_names" type="list[str]">
  Optional list of column names for the feature matrix. Must have the same length as `X.shape[1]`. If omitted, columns are named `feature_0`, `feature_1`, etc.
</ParamField>

```python
import numpy as np
import outerproduct as op

X = np.array([[1200, 3, 2], [850, 2, 1], [2100, 4, 3]])
y = np.array([0, 0, 1])

dataset = op.Dataset.from_numpy(
    X,
    y,
    feature_names=["sqft", "bedrooms", "bathrooms"],
)
print(dataset.feature_names)  # ['sqft', 'bedrooms', 'bathrooms', 'y']
```

## Instance Attributes

After creating a Dataset, the following attributes are available for inspection:

<ResponseField name="n_samples" type="int">
  The number of rows in the dataset.
</ResponseField>

<ResponseField name="n_features" type="int">
  The total number of columns in the dataset. Because the target column is not designated on the `Dataset` itself, all columns — including any `y` array appended via `from_numpy(y=...)` — are counted here.
</ResponseField>

<ResponseField name="feature_names" type="list[str]">
  Ordered list of column names. Matches the column order of the original data source.
</ResponseField>

```python
dataset = op.Dataset.from_csv("customers.csv")

print(dataset.n_samples)      # e.g. 50000
print(dataset.n_features)     # e.g. 12
print(dataset.feature_names)  # ['age', 'income', 'tenure', ...]
```

## Methods

### `dataset.head()`

Return a preview of the first rows of the dataset. Useful for quickly verifying that data loaded correctly.

```python
print(dataset.head())
```

<ResponseField name="return value" type="pd.DataFrame">
  A pandas DataFrame containing the first rows of the dataset, similar to `df.head()`.
</ResponseField>

---

### `dataset.to_pandas()`

Convert the dataset back to a pandas DataFrame.

```python
df = dataset.to_pandas()
```

<ResponseField name="return value" type="pd.DataFrame">
  A full pandas DataFrame representation of the dataset, with column names preserved.
</ResponseField>

```python
# Drop the label before running inference
df = dataset.to_pandas()
X_test = df.drop(columns=["churn"])
test_dataset = op.Dataset(X_test)
```

## Column Schema

Every column in a `Dataset` carries a `Column` schema object that captures its data type and any encoding or imputation hints. By default the schema is **inferred automatically** from the data — you rarely need to set it manually.

If you need to override the inferred schema for one or more columns, pass a `columns=` mapping when constructing the Dataset:

```python
from outerproduct.dataset import Column

dataset = op.Dataset.from_csv(
    "customers.csv",
    columns={
        "account_age_days": Column(dtype="numeric"),
        "plan_tier": Column(dtype="categorical"),
    },
)
```

<Note>
  The target (label) column is **not** declared on the `Dataset`. You specify it later using the `label_column=` argument in [`Trainer.configure()`](/sdk/trainer) or `op.reasoning.fit()`.
</Note>

## Complete Example

<CodeGroup>

```python From CSV
import outerproduct as op

op.init()

dataset = op.Dataset.from_csv("loans.csv")
print(f"Loaded {dataset.n_samples} rows with {dataset.n_features} features.")
print(dataset.head())
```

```python From pandas
import pandas as pd
import outerproduct as op

op.init()

df = pd.read_csv("loans.csv")
dataset = op.Dataset.from_pandas(df)
print(dataset.feature_names)
```

```python From NumPy
import numpy as np
import outerproduct as op

op.init()

X = np.random.rand(1000, 5)
y = (X[:, 0] > 0.5).astype(int)

dataset = op.Dataset.from_numpy(
    X,
    y,
    feature_names=["f0", "f1", "f2", "f3", "f4"],
)
print(dataset.n_samples, dataset.n_features)
```

```python From Parquet
import outerproduct as op

op.init()

# Requires: pip install outerproduct[parquet]
dataset = op.Dataset.from_parquet("warehouse/transactions.parquet")
print(dataset.head())
```
