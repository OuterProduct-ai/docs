## `ModelParamSpace`

One model family's search: searched dimensions + fixed constants.

Build fluently (`ModelParamSpace(family="tabm").float("lr", 1e-4, 3e-3, log=True)`)
or from a dict. As a convenience an input dict may carry a single `params`
map mixing distributions and constants; they are split into `search` /
`fixed` (the canonical, serialized shape).

## `Float`

A continuous float dimension, optionally log-scaled.

## `Int`

An integer dimension, optionally log-scaled.

## `Categorical`

A choice over an explicit list of values (uniform — optuna has no weights).

## `Mixture`

A spike-and-slab dimension: `spike` (default 0.0) with some probability,
otherwise a draw from `inner`. Replaces the old `zero_or_*` composite
tags; the sampler draws it as a gate + conditional value (the inner leaf is
only suggested when the gate fires).

## `Optimizer`

How an HPO job searches: a sampler plus a round-structured trial budget.

Each optimization round proposes `n_trials_per_step` trials, evaluates
them, folds the results back, then proposes the next round; `n_steps`
rounds run in sequence. The total trials searched is
`n_trials_per_step * n_steps`.
