## `Trainer`

Configures and runs training to produce a [`Model`](/sdk/model#model).

The full lifecycle is:

1. [`Trainer.configure`](/sdk/trainer#trainer-configure) — describe what to train, where, and how.
2. [`Trainer.run`](/sdk/trainer#trainer-run) — submit the configured plan and return a
   [`TrainingJob`](/sdk/jobs#trainingjob) handle. Call
   [`TrainingJob.wait`](/sdk/jobs#trainingjob-wait) to block for the trained
   [`Model`](/sdk/model#model).

[`Trainer`](/sdk/trainer#trainer) resolves to a plain [`Model`](/sdk/model#model). To
produce a `ReasoningModel` (with explain,
get_global_drivers, scenario, segment methods) use
[`fit`](/sdk/reasoning#op-reasoning-fit) instead.

### `Trainer.configure()`

```python
configure(df: DataFrame, *, task: Task | None = None, hpo_space: HPOSpace | None = None, metric: Metric | list[Metric] | None = None) -> Trainer
```

Configure a trainer for `df` and return it ready to [`run`](/sdk/trainer#trainer-run).

**Parameters**

<ParamField body="df" type="DataFrame" required>
  Training data — `op.table(name)` over a registered source,
optionally filtered/selected.
</ParamField>

<ParamField body="task" type="Task | None">
  The learning task and its target columns — one of
`Regression`, `Binclass`, `Multiclass`, `Forecasting`,
`SequenceRegression`, `SequenceBinclass`, or
`SequenceMulticlass` (each carries `label_column`; the
time-series / sequence variants also carry `id_column` /
`timestamp_column`). Required for supervised training.
</ParamField>

<ParamField body="hpo_space" type="HPOSpace | None">
  The search space — candidate model families and, per family, which
hyperparameters are fixed vs searched. Must be a built
[`HPOSpace`](/sdk/hpo#hpospace): construct it with
`HPOSpace.from_dict` or `HPOSpace().add(...)` — a raw dict is
rejected. Defaults to a curated space chosen from the dataset's size
and schema.
</ParamField>

<ParamField body="metric" type="Metric | list[Metric] | None">
  One metric to optimise directly, or a list to optimise jointly
via Optuna's native multi-objective (Pareto) search, with no
metric privileged.
</ParamField>

**Returns**

<ResponseField name="returns" type="Trainer">
  A configured trainer. Call [`run`](/sdk/trainer#trainer-run) to start training.
</ResponseField>

### `Trainer.run()`

```python
run(optimizer: Optimizer | None = None, *, n_cv_splits: int | None = None, ensemble: bool = False, random_state: int = 42) -> TrainingJob
```

Submit the configured training plan and return a job handle.

**Parameters**

<ParamField body="optimizer" type="Optimizer | None">
  How to search the space — the sampler (`"tpe"` / `"random"` /
`"cmaes"`) and a round-structured trial budget
(`n_trials_per_step` proposed per round × `n_steps` rounds).
If omitted, the server uses a default optimizer.
</ParamField>

<ParamField body="n_cv_splits" type="int | None">
  Number of cross-validation splits. If omitted, the server
chooses a default.
</ParamField>

<ParamField body="ensemble" type="bool">
  Whether to ensemble the top-performing trials.
</ParamField>

<ParamField body="random_state" type="int">
  Random seed for reproducibility.
</ParamField>

**Returns**

<ResponseField name="returns" type="TrainingJob">
  Handle to the running job. Call [`TrainingJob.wait`](/sdk/jobs#trainingjob-wait) to block until training finishes and return the trained [`Model`](/sdk/model#model), or use `Job.status` to poll. To get a `ReasoningModel` instead, use [`fit`](/sdk/reasoning#op-reasoning-fit).
</ResponseField>

## `Metric`

An evaluation metric used to score candidate models.
