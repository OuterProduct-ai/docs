## `Workspace`

A client-bound dataframe context: resolves the org's source tables over
HTTP and ingests new ones (S3 reference or upload).

### `Workspace.table()`

```python
table(name: str) -> DataFrame
```

### `Workspace.sql()`

```python
sql(query: str) -> DataFrame
```

### `Workspace.upload()`

```python
upload(table_name: str, data: pa.Table, *, client: OuterProductClient | None = None) -> DataFrame
```

Upload `data` (a pyarrow Table) and register it as `table_name`.

Serializes to Parquet and uploads it via `POST /v1/source_tables/upload`.
Returns the lazy `DataFrame`; its schema is resolved on first reference.

### `Workspace.register_s3()`

```python
register_s3(table_name: str, url: str, connector: str, *, client: OuterProductClient | None = None) -> DataFrame
```

Register external parquet at `url` (`s3://…`) as `table_name`.

`connector` is the name of a stored S3 connector credential (created in
console.op) that authenticates the read. Returns the lazy `DataFrame`.
