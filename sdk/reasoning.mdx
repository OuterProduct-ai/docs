## `op.reasoning.fit()`

```python
fit(df: DataFrame, *, task: Task | None = None, hpo_space: HPOSpace | None = None, optimizer: Optimizer | None = None, random_state: int = 42) -> ReasoningFitJob
```

Fit a [`ReasoningModel`](/sdk/model#reasoningmodel) via the OuterProduct API.

Supervised training on `task`'s `label_column`: the resulting
reasoning model produces both predictions and feature-level explanations.

The trainer-style `hpo_space` is mirrored here so a reasoning fit is a
single self-contained call — no need to construct a separate
[`Trainer`](/sdk/trainer#trainer).

### Parameters

<ParamField body="df" type="DataFrame" required>
  Training data.
</ParamField>

<ParamField body="task" type="Task | None">
  The learning task and its target columns (e.g.
`op.Regression(label_column=...)`). Required for supervised fits.
</ParamField>

<ParamField body="hpo_space" type="HPOSpace | None">
  The surrogate search space (a single model family). Must be
a built [`HPOSpace`](/sdk/hpo#hpospace) — construct
it with [`HPOSpace.from_dict`](/sdk/hpo#hpospace-from_dict)
or `HPOSpace().add(...)` (a raw dict is rejected). Defaults to a
surrogate chosen server-side by dataset size.
</ParamField>

<ParamField body="optimizer" type="Optimizer | None">
  How to search the surrogate space — the sampler and a
round-structured trial budget (`n_trials_per_step` × `n_steps`). If
omitted, the server uses a default optimizer.
</ParamField>

<ParamField body="random_state" type="int">
  Random seed for reproducibility.
</ParamField>

### Returns

<ResponseField name="returns" type="ReasoningFitJob">
  Handle to the running fit job. Call [`ReasoningFitJob.wait`](/sdk/jobs#reasoningfitjob-wait) to block for the trained [`ReasoningModel`](/sdk/model#reasoningmodel), or use [`Job.status`](/sdk/jobs#job-status) / [`Job.results`](/sdk/jobs#job-results) to poll. The reasoning model supports [`ReasoningModel.explain`](/sdk/model#reasoningmodel-explain), [`ReasoningModel.get_global_drivers`](/sdk/model#reasoningmodel-get_global_drivers), and [`ReasoningModel.scenario`](/sdk/model#reasoningmodel-scenario).
</ResponseField>

## `Reasoning`

A single explanation: feature attributions plus optional rules.

Returned by [`ReasoningModel.explain`](/sdk/model#reasoningmodel-explain)
and
[`ReasoningModel.get_global_drivers`](/sdk/model#reasoningmodel-get_global_drivers).

### Fields

<ParamField body="feature_names" type="list[str]">
  Names of the raw input features. These align with the
last axis of `attributions` only when the model has no categorical
features. When it does, the model attributes in an encoded space
(categoricals are one-hot expanded), so `attributions` is wider
than `feature_names`; use `encoded_feature_names` to label the
attribution columns in that case.
</ParamField>

<ParamField body="attributions" type="np.ndarray">
  Per-feature contribution values, in the encoded feature
space. Shape `(n_samples, n_encoded_features)` for local
explanations, or `(n_encoded_features,)` for global / model-wide
views. The last axis aligns with `encoded_feature_names` when that
is present, else with `feature_names`.
</ParamField>

<ParamField body="encoded_feature_names" type="list[str] | None">
  Encoded column labels aligned to the last axis
of `attributions` (categorical features are one-hot expanded, e.g.
`"State__KS"`). Present only when the model has categorical
features — otherwise `None` and `feature_names` already aligns.
</ParamField>

<ParamField body="rules" type="list[str] | None">
  Human-readable decision rules associated with the prediction
(for example, `"age > 50 AND tenure < 2"`).
</ParamField>

<ParamField body="metadata" type="dict[str, Any] | None">
  Free-form provenance fields — engine name, version, timing,
etc. Not part of the API contract.
</ParamField>
