different class count as a hard error rather than silently widening.

## `Forecasting`

Forecast a target's future values from its own past.

Rows are grouped into series by `id_column` and ordered within a series
by `timestamp_column`; the model uses values up to time `t` to predict
the next `horizon` steps. Accepted and validated on the wire but not yet
executable server-side.

### Fields

<ParamField body="label_column" type="str">
  Target column whose future values are forecast.
</ParamField>

<ParamField body="id_column" type="str">
  Series/entity identifier column.
</ParamField>

<ParamField body="timestamp_column" type="str">
  Within-series ordering timestamp column.
</ParamField>

<ParamField body="horizon" type="int">
  Number of steps ahead to forecast.
</ParamField>

<ParamField body="lookback" type="int | None">
  History window length; None uses all available history.
</ParamField>
