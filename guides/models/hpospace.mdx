---
title: "HPO"
---

The HPO space specifies which model families to try and the hyperparameter ranges to tune for each. Build a `ModelParamSpace` per family, then add them to an `HPOSpace`.

Supported model families include:

- **xRFM:** kernel-based recursive feature machine ([link](https://arxiv.org/abs/2508.10053))
- **TabM:** MLP-style tabular net ([link](https://arxiv.org/abs/2410.24210))
- **TabICL:** tabular foundation model ([link](https://arxiv.org/abs/2602.11139))

Each `ModelParamSpace` accepts `.float()`, `.int()`, and `.categorical()` hyperparameters; pass `log=True` for log-scale search.

```python
# xRFM
xrfm = (
    op.ModelParamSpace(family="xrfm")
    .float("bandwidth", 1.0, 20.0, log=True)
    .float("exponent", 0.5, 2.0)
    .int("iters", 4, 6)
)

# TabM
tabm = (
    op.ModelParamSpace(family="tabm")
    .float("lr", 1e-4, 3e-3, log=True)
    .categorical("n_blocks", [1, 2, 3, 4])
    .int("d_block", 64, 512, log=True)
)

# TabICL
tabicl = (
    op.ModelParamSpace(family="tabicl")
    .int("n_estimators", 1, 32, log=True)
    .float("softmax_temperature", 0.5, 2.0)
    .categorical("average_logits", [True, False])
    .categorical("norm_methods", ["none", "power", "quantile"])
)

hpo_space = op.HPOSpace().add(tabm).add(xrfm)
```

> **Note:** Hyperparameter ranges are optional. If you don't specify them, OuterProduct uses sensible defaults for each model family.
