---
title: "Task"
---

A `Task` object declares the kind of predictive modeling and the target column name within the data set. OuterProduct supports multiple tasks across tabular data.

- `op.Binclass()` — binary classification
- `op.Multiclass()` —  multi-class classification
- `op.Regression()` — continuous numeric predictions

```python
# Binary: will this customer churn?
task = op.Binclass(label_column="Churn")

# Multiclass: which playlist type?
task = op.Multiclass(label_column="Playlist")

# Regression: what lifetime value?
task = op.Regression(label_column="LTV")
```
