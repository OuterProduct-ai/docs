---
title: "Training"
---

`op.reasoning.fit()` submits a training job: your `task` defines what to predict, `metrics` define what to optimize for, and the `hpo_space` and `optimizer` control the search. It returns a `ReasoningFitJob`.

Call `.wait()` to block until results are ready. It returns the single best model, or, when you optimize more than one metric, the **Pareto frontier** of models trading them off.

```python
job = op.reasoning.fit(
    train_tbl.drop(split_id),      # all features except the ID column
    task=task,
    metrics=["auc", "neg_class_error"],
    hpo_space=hpo_space,
    optimizer=optimizer,
)
curve = job.wait()
```

**Arguments**

- `df` _(required)_ — the training table, passed positionally. **Must be an OuterProduct dataframe**. Every column is treated as a feature except those named by the task (label, id, timestamp).
- `task` _(required)_ — the kind of predictive modeling problem.
- `metrics` — list of metric names to optimize. One metric selects a single best model; several trigger multi-objective (Pareto) optimization. Defaults to a task-appropriate metric.
- `hpo_space` — the `HPOSpace` to search. Defaults to a server-chosen space.
- `optimizer` — the `Optimizer` . Defaults to TPE.

**Supported metrics**

- `auc` — AUC
- `neg_class_error` — negative misclassification rate
- `neg_rmse` — negative RMSE
