---
title: "DataFrame"
---

After you registered your data, you can create an OuterProduct`DataFrame` by querying against the tables in your workspace. The `DataFrame` is built in Rust on [Apache DataFusion](https://datafusion.apache.org/), so that queries run as real relational plans against all registered data sources simultaneously.

<Tip>
  An OuterProduct `DataFrame` is a lazy-query, meaning that it will not materialize data until it is needed for computation.  As a result, you can query data at any scale as if it were in memory.
</Tip>

## Creating a DataFrame

Get a `DataFrame` for a registered table with `Workspace.table()`:

```python
customers = ws.table("customers")
```

Or express the query in SQL:

```python
top_regions = ws.sql("SELECT region, count(*) AS n FROM customers GROUP BY region")
```

## Getting results

Creating a `DataFrame` only builds a query plan (it doesn't run anything). A **terminal** method sends the whole plan to OuterProduct's servers, runs it, and returns a concrete result:

```python
customers = ws.table("customers")   # nothing runs yet

customers.show()          # prints a preview (default 20 rows)
customers.count()         # → int, the row count
table = customers.materialize()   # → PyArrow Table with all rows
```

Convert the materialized `Table` into whatever you need:

```python
table = customers.materialize()
table.to_pandas()   # pandas DataFrame
table.to_pylist()   # list of row dicts
```
