---
title: "Local files"
---

Register a local **CSV**, **Parquet**, or **JSON** file with `register_csv` / `register_parquet` / `register_json`. Each reads the file, uploads the rows, registers a source table, and returns its `DataFrame`.

```python
# path first, table name second (or omit to use the file stem)
op_df = ws.register_parquet("data/segments.parquet", "segments")
op_df = ws.register_csv("data/customers.csv", table_name="customers")
op_df = ws.register_json("data/events.json", table_name="events")

op_df = ws.register_parquet("data/events.parquet")  # table name → "events"
```

| Format | Method | Notes |
| :-- | :-- | :-- |
| Parquet | `register_parquet(path, table_name=…)` | Compressed, columnar, types preserved. |
| CSV | `register_csv(path, table_name=…)` | Types inferred on read. |
| JSON | `register_json(path, table_name=…)` | Newline-delimited JSON, types inferred on read. |

<Tip>
  Use a Parquet file instead of CSV when your dataset is large. Parquet files are compressed and columnar, so they upload faster and consume less bandwidth. They also preserve column types, while CSV and JSON values are inferred on read.
</Tip>
