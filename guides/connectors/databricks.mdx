`ws.register_databricks` lets OuterProduct read data from your Databricks SQL warehouse or cluster at query time. You create a Databricks connector in the [OuterProduct Console](https://console.outerproduct.com) with a personal access token, then reference the connector by name in the SDK. No Databricks token is passed through the SDK.

## Give your OuterProduct account permission to read Databricks

Before registering a Databricks table from Python, create a connector in the OuterProduct Console and generate a personal access token in Databricks.

<Steps>
  <Step title="Open the New Connector wizard">
    Log in to [console.outerproduct.com](https://console.outerproduct.com) and navigate to **Connectors**. Click **New Connector**, give your connector a name, and select **Databricks**.
  </Step>
  <Step title="Generate a personal access token in Databricks">
    In your Databricks account, navigate to **Settings → Developer → Access tokens** and click **Generate new token**. When prompted, select **Other APIs** as the token type. Copy this token, as you'll need it in the next step.

    <Note>
      Assign the token to a Databricks user or service principal that has `SELECT` access on the tables you want OuterProduct to read.
    </Note>
  </Step>
  <Step title="Enter your Databricks connection details">
    Paste your Databricks server hostname, HTTP path, and the personal access token you just generated into the connector wizard.
  </Step>
  <Step title="Save the connector">
    Click **Add connector**. OuterProduct validates the Databricks connection before saving the connector.
  </Step>
</Steps>

## Use it from Python

Once your connector is saved in the Console, register the Databricks table as a source table with `ws.register_databricks`. Pass a table name, the source locator in `catalog.schema.table` form, and the `connector` name from the Console. The call returns a `DataFrame` you can train on, or query later with `ws.table(name)` or `ws.sql(...)`.

```python
import outerproduct as op

op.init()  # reads OUTERPRODUCT_API_KEY from the environment
ws = op.Workspace()

ws.register_databricks("customers", "main.default.customers", connector="prod-databricks")

# Build the training set as a query over the registered source.
train = ws.table("customers").filter(op.col("signup_year") >= 2020)

model = op.reasoning.fit(train, task=op.Binclass(label_column="churn")).wait()
```

<Tip>
  The server hostname and HTTP path are configured once in the Console connector, not in the SDK. Find them in the Databricks SQL warehouse UI under **Connection details**. The HTTP path changes if you switch warehouses, so update your connector accordingly.
</Tip>

<Warning>
  The `connector` argument must match exactly the name you gave your connector in the OuterProduct Console.
</Warning>
