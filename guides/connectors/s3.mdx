`ws.register_s3` lets OuterProduct read data directly from your Amazon S3 bucket at query time. When you sign up for OuterProduct, we internally provision an IAM role for your account. To connect your OuterProduct account to your bucket, you attach a policy to your bucket that gives read access for the IAM role we provisioned for your account. 

## Add an S3 credential in the Console

Before registering an S3 table from Python, create a credential in the OuterProduct Console and set up the corresponding IAM role in AWS.

<Steps>
  <Step title="Open the New Connector wizard">
    Log in to [console.outerproduct.com](https://console.outerproduct.com) and navigate to **Connectors**. Click **New Connector**, give your connector a name, and select **S3**.
  </Step>
  <Step title="Enter your S3 bucket information">
    Paste your S3 bucket details into the first page of the wizard, then click **Next**.
  </Step>
  <Step title="Attach the generated policy to your account">
    The Console displays a JSON trust policy. In your AWS account, navigate to **IAM → Roles → Create Role**. Choose **Custom Trust Policy** and paste the JSON provided by the Console.

    <Note>
      This trust policy gives read access to your bucket for your OuterProduct-provisioned IAM role.
    </Note>
  </Step>
  <Step title="Save the connector">
    Return to the OuterProduct Console and complete the wizard. Your connector is now ready to use from the SDK.
  </Step>
</Steps>

## Use it from Python

Once your credential is saved in the Console, register the S3 file as a source table with `ws.register_s3`. Pass a table name, the full `s3://` URI of the folder or file corresponding to a parquet table, and the `connector` name from the Console. The call returns a `DataFrame` you can train on, or query later with `ws.table(name)` or `ws.sql(...)`.

```python
import outerproduct as op

op.init()  # reads OUTERPRODUCT_API_KEY from the environment
ws = op.Workspace()

ws.register_s3("customers", "s3://my-bucket/data/customers.parquet", connector="prod-aws")

# Build the training set as a query over the registered source.
train = ws.table("customers").filter(op.col("signup_year") >= 2020)

model = op.reasoning.fit(train, task=op.Binclass(label_column="churn")).wait()
```

<Tip>
  The `connector` argument must match exactly the name you gave your connector in the OuterProduct Console.
</Tip>

<Warning>
  OuterProduct assumes the IAM role when it reads the table. Make sure the role's trust policy and inline permissions policy are both saved in AWS before you register the table.
</Warning>
